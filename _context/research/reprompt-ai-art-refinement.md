# RePrompt: Automatic Prompt Editing to Refine AI-Generative Art Towards Precise Expressions

**arXiv ID:** 2302.09466
**Venue:** CHI '23 (2023 CHI Conference on Human Factors in Computing Systems)
**Authors:** Yunlong Wang, Shuyuan Shen, Brian Y. Lim
**Source:** https://arxiv.org/abs/2302.09466

## Abstract

The research investigates how well text-to-image AI systems translate emotional intent into visual output. The team created RePrompt, a system that automatically refines text prompts to enhance emotional expressiveness in generated images.

The method identifies text features—including "the number and concreteness of nouns"—and trains a predictive model to understand how these features affect image generation. Using model explanations, the researchers developed guidelines for adjusting prompts to better convey intended emotions.

## Key Elements

- **Focus:** Emotional expressiveness of AI-generated imagery
- **Approach:** Automatic prompt refinement based on text analysis
- **Methodology:** Proxy model training with explainability analysis
- **Validation:** Both computational simulation and human user studies

## Results

Testing revealed that RePrompt notably enhanced emotional communication in generated images, with particularly strong improvements for depicting negative emotions.

## Relevance

This research dovetails with iteration/negation workflows in creative AI, helping frame how prompt refinement and emotional expressiveness connect in generative art pipelines.
