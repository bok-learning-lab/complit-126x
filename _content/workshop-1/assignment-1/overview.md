# Assignment 1: Build an Encyclopedia

## The Goal

You're going to build a tool that creates an illustrated encyclopedia from any collection of texts, on any topic you choose.

By the end, you'll have:
- A folder of texts (poems, essays, novels, whatever)
- A topic you want to explore ("birds", "death", "the sea", "machines")
- Code that finds every relevant passage, extracts structured data, generates artwork, and saves it all

## The Example: Birds in Poetry

To learn the pieces, we'll work through a concrete example: finding **birds** that appear in **famous poems**.

You'll end up with encyclopedia entries like:

> **The Raven**
> *Source: Edgar Allan Poe, "The Raven"*
> A dark, ominous bird that visits a grieving narrator at midnight, repeating only the word "Nevermore."
> *Themes: Death, Loss, Madness*

...plus AI-generated artwork for each entry, all saved as JSON + images you can use in an app.

## Your Final Project

Once you've worked through the tutorials, you'll adapt the code for your own project:

1. **Pick your texts** — What corpus interests you?
2. **Pick your topic** — What do you want to find?
3. **Define your schema** — What data do you want for each entry?
4. **Run it** — Let the code do the work
5. **Use it** — The JSON + images are ready for a website, presentation, or further analysis

## Getting Started

Open **01-variables.ipynb** and run through each notebook in order. They're short — most take 5-10 minutes.

You don't need to understand every line of Python. Focus on:
- What does this code *do*?
- What would I change to make it *mine*?
