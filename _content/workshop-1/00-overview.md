# Vibe Coding Workshop: Overview

Welcome to a different kind of coding workshop.

## What You'll Learn (and Why It Matters)

In the next 90 minutes, you'll learn to **create working code without understanding every line**. This might sound strange—even irresponsible—but it's actually a critical literacy for the world we're living in.

### The Traditional Approach (Not What We're Doing)

Most coding courses start with building blocks:
- What is a variable?
- What is a string?
- What is a function?
- What is a loop?

Then, after weeks or months, you finally build something useful.

### The Vibes-First Approach (What We ARE Doing)

Today, we're flipping that entirely:

1. **Ask AI to write code** (code you don't understand)
2. **Run it and see it work** (experience before understanding)
3. **Verify, test, and probe** (develop trust through checks)
4. **Unpack selectively** (understand what matters, when it matters)
5. **Iterate and extend** (build on what works)

## Why This Approach?

### The World Has Changed

**Before 2023:** To write code, you had to understand code.

**After 2023:** AI can write code from plain English descriptions. The bottleneck has shifted from "can you write syntax?" to "can you specify what you want, verify what you got, and iterate toward something useful?"

### This Is a Real Literacy

You might think: "Isn't this just cheating? Aren't I supposed to understand everything?"

But consider:
- **Drivers** don't understand fuel injection systems
- **Editors** don't read every word of every page before publication
- **Statisticians** don't implement optimization algorithms from scratch
- **Musicians** often learn by ear before learning theory

In each case, there's a kind of **operational competence under partial understanding**.

You learn to:
- Know when something is working or broken
- Know how to test and verify
- Know when you need to dig deeper
- Know how to ask for help (from AI, documentation, or humans)

### What Makes This Responsible (Not Reckless)

"Vibe coding" doesn't mean "trust everything blindly."

It means:
- **Specification:** Clearly state what should happen
- **Verification:** Check that it actually happens
- **Iteration:** Refine when it doesn't
- **Selective reading:** Understand the parts that matter
- **Incremental trust:** Build confidence through testing

This is exactly how humanities scholars work with texts:
- You don't read every word of every source
- You sample, test claims, check evidence
- You know how to spot red flags
- You build arguments on foundations you can defend

**Vibe coding applies scholarly verification practices to AI-generated code.**

## What You'll Build Today

1. **Word frequency analyzer** (via Gemini, quickly)
2. **Python text analysis tools** (in GitHub Codespaces)
3. **Your own working code** (that you can explain, test, and trust)

By the end, you'll have:
- Working code in your repository
- The ability to specify, verify, and iterate
- Confidence that you can automate tedious tasks
- A foundation to build on (if you choose)

## Who This Is For

This workshop is designed for:
- **Humanities students and faculty** who want computational superpowers
- **Anyone intimidated by "learning to code"** who wants a faster on-ramp
- **People who need to get things done** more than they need to become software engineers
- **Critical thinkers** who want to understand how AI works by working *with* AI

## What This Is NOT

This is not:
- ❌ A traditional CS course (we won't start with print("Hello World"))
- ❌ "Learning to be a software engineer" (that takes years, not minutes)
- ❌ "Blind trust in AI" (we'll verify everything)
- ❌ A replacement for deep technical knowledge (we're building a different skill)

## The Structure

1. **Setup (10 min)** — Get your environment running
2. **Gemini warmup (20 min)** — Quick wins with AI
3. **Python notebooks (50 min)** — Hands-on coding in Codespaces
4. **Reflection & next steps (10 min)** — Where you go from here

## The Meta-Skill You're Learning

The real skill isn't "Python syntax" or "JavaScript frameworks."

The real skill is: **How do I work effectively with powerful systems I don't fully understand but can steer through language?**

This applies to:
- AI coding assistants
- Data analysis tools
- API integrations
- Computational research methods
- Future tools we can't even imagine yet

## Ready?

This will feel weird at first. You'll be working with code before you understand it. That discomfort is the point—you're building a new kind of literacy.

Let's begin.
