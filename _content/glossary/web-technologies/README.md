# Web Technologies Glossary

Modern web development: languages, frameworks, and platforms.

## The Languages

**Core languages for web development:**
- **[JavaScript](./javascript.md)** — The language of web interactivity
- **[TypeScript](./typescript.md)** — JavaScript with type safety

**Note:** This workshop focuses on Python, but these are useful for building web interfaces.

## The Framework & Platform

**Building and deploying web apps:**
- **[React](./react.md)** — Component-based UI library
- **[Next.js](./nextjs.md)** — React framework with server features
- **[Vercel](./vercel.md)** — Hosting platform for Next.js

## Why These Together?

These technologies form a complete stack:

```
React          → Build UI components
Next.js        → Add routing, server features
TypeScript     → Add type safety
Vercel         → Deploy to production
```

**Result:** Complete web application, frontend to production.

## The Modern Web Stack

### Traditional Approach

### Modern Approach

## Example: Text Analyzer Interface

```typescript
// Full Next.js + TypeScript + React component
'use client'

import { useState } from 'react';

interface AnalysisResult {
    wordCount: number;
    themes: string[];
    sentiment: string;
}

export default function Analyzer() {
    const [text, setText] = useState('');
    const [result, setResult] = useState<AnalysisResult | null>(null);
    const [loading, setLoading] = useState(false);

    const analyze = async () => {
        setLoading(true);
        const res = await fetch('/api/analyze', {
            method: 'POST',
            body: JSON.stringify({ text })
        });
        const data = await res.json();
        setResult(data);
        setLoading(false);
    };

    return (
        <div className="p-8">
            <textarea
                value={text}
                onChange={(e) => setText(e.target.value)}
                className="w-full h-40 p-2 border rounded"
            />
            <button
                onClick={analyze}
                disabled={loading}
                className="mt-4 px-6 py-2 bg-blue-500 text-white rounded"
            >
                {loading ? 'Analyzing...' : 'Analyze'}
            </button>
            {result && (
                <div className="mt-6 p-4 bg-gray-50 rounded">
                    <p>Words: {result.wordCount}</p>
                    <p>Themes: {result.themes.join(', ')}</p>
                    <p>Sentiment: {result.sentiment}</p>
                </div>
            )}
        </div>
    );
}
```

This would be generated by AI based on your prompt!

## Deployment Example

```bash
# 1. Create Next.js app with AI-generated code
npx create-next-app@latest my-analyzer

# 2. Add your components and API routes

# 3. Push to GitHub
git push origin main

# 4. Deploy to Vercel
vercel

# Done! Live at: https://my-analyzer.vercel.app
```

From idea to production in minutes.
