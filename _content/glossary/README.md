# Workshop Glossary

A reference guide for key concepts in the Vibe Coding Workshop.

## Structure

The glossary is organized into five main categories:

### [python-basics/](./python-basics/)
Core Python programming concepts you'll encounter in the workshop.

**Key terms:**
- [Python](./python-basics/python.md) — The programming language itself
- [Function](./python-basics/function.md) — Reusable blocks of code
- [Loop](./python-basics/loop.md) — Repeating code (the "ChatGPT can't do this" moment)
- [Variable](./python-basics/variable.md) — Named containers for values
- [String](./python-basics/string.md) — Text data
- [List](./python-basics/list.md) — Ordered collections
- [Dictionary](./python-basics/dictionary.md) — Key-value pairs

### [ai-concepts/](./ai-concepts/)
Terms related to working with AI models and APIs.

**Key terms:**
- [API](./ai-concepts/api.md) — How code talks to external services
- [Prompt](./ai-concepts/prompt.md) — Instructions you give to AI
- [Model](./ai-concepts/model.md) — The AI system generating responses
- [Token](./ai-concepts/token.md) — Basic unit of text AI processes
- [Context Window](./ai-concepts/context-window.md) — Maximum text a model can handle
- [Context Engineering](./ai-concepts/context-engineering.md) — Shaping what the LLM knows (critical!)
- [RAG](./ai-concepts/rag.md) — Automatically retrieving relevant context

### [development-tools/](./development-tools/)
Essential tools and practices for modern development.

**Key terms:**
- [Environment Variables](./development-tools/environment-variables.md) — Configuration outside code
- [API Keys](./development-tools/api-keys.md) — Secret passwords for API access
- [Codespaces](./development-tools/codespaces.md) — Cloud-based development environment
- [JSON](./development-tools/json.md) — Format for structured data

### [web-technologies/](./web-technologies/)
Modern web development languages, frameworks, and platforms.

**Key terms:**
- [JavaScript](./web-technologies/javascript.md) — The language of web interactivity
- [TypeScript](./web-technologies/typescript.md) — JavaScript with type safety
- [React](./web-technologies/react.md) — Component-based UI library
- [Next.js](./web-technologies/nextjs.md) — React framework with server features
- [Vercel](./web-technologies/vercel.md) — Hosting platform for Next.js

### [vibe-coding/](./vibe-coding/)
The workshop's methodology and approach to learning.

**Key terms:**
- [Vibe Coding](./vibe-coding/vibe-coding.md) — The overall approach
- [Specification](./vibe-coding/specification.md) — Clearly stating what should happen
- [Verification](./vibe-coding/verification.md) — Checking code works correctly
- [Iteration](./vibe-coding/iteration.md) — Refining through repeated cycles
- [Selective Reading](./vibe-coding/selective-reading.md) — Reading code strategically

## How to Use This Glossary

**During the workshop:**
- Reference terms as you encounter them
- Don't try to memorize — just familiarize
- Come back when you need clarification

**After the workshop:**
- Review concepts you want to understand better
- Use as a reference for your own projects
- Share with others learning this approach

## What's Essential vs. Optional

### Core to the Workshop (Must know)
- **python-basics** — You'll write Python code
- **ai-concepts** — You'll work with AI APIs
- **development-tools** — You'll use these practices
- **vibe-coding** — This is the methodology

### Extensions (Nice to have)
- **web-technologies** — Optional: for building web interfaces

**Focus:** Python and vibe coding practices. Everything else is reference material.

## The Meta-Pattern

Notice the pattern across all categories:

1. **You don't need to know everything**
2. **Focus on what matters for your current task**
3. **Build understanding incrementally**
4. **Verify through doing, not memorization**

This glossary follows the same philosophy — use it as needed, not as required reading.
