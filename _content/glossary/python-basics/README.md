# Python Basics Glossary

Core Python programming concepts you'll encounter in the workshop.

## The Fundamentals

These are the building blocks you'll see in every Python program:

- **[Variable](./variable.md)** — Named containers for values
- **[String](./string.md)** — Text data
- **[Function](./function.md)** — Reusable blocks of code

## The Power Tools

These concepts unlock automation and scale:

- **[Loop](./loop.md)** — Repeating operations (the "ChatGPT can't do this" moment)
- **[List](./list.md)** — Ordered collections of items
- **[Dictionary](./dictionary.md)** — Key-value pairs for structured data

## Learning Approach

You don't need to master these concepts before using them.

The workshop approach:
1. **See it work** (in generated code)
2. **Recognize the pattern** (oh, that's a loop)
3. **Understand what it does** (processes multiple items)
4. **Learn details on demand** (when you need to modify it)

## The Critical Concepts for This Workshop

If you only remember three things:

1. **Functions** let you reuse code
2. **Loops** let you process many items automatically
3. **Dictionaries** let you store structured data (like word counts)

Everything else builds on these foundations.
