# Development Tools Glossary

Essential tools and concepts for modern software development.

## Core Development Concepts

**Configuration and Secrets:**
- **[Environment Variables](./environment-variables.md)** — Configuration outside code
- **[API Keys](./api-keys.md)** — Secret passwords for API access

**Development Environments:**
- **[Codespaces](./codespaces.md)** — Cloud-based VSCode environment

**Data Formats:**
- **[JSON](./json.md)** — Universal data exchange format

## Why These Matter

These aren't AI-specific or Python-specific — they're fundamental to all modern development:

### Environment Variables
Every real project uses them:
- Store secrets safely
- Configure different environments
- Keep sensitive data out of code

### API Keys
Essential for working with services:
- Authenticate your requests
- Track usage and billing
- Secure access to APIs

### Codespaces
Modern development without setup:
- Zero installation
- Consistent environment
- Professional workflow

### JSON
The language of APIs:
- How services communicate
- Standard data format
- Used everywhere

## Development Workflow

These tools enable the modern workflow:

```
1. Code in Codespaces
   ↓
2. Use environment variables for config
   ↓
3. Store API keys securely
   ↓
4. Exchange data via JSON
   ↓
5. Deploy to production
```
