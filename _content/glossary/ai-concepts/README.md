# AI Concepts Glossary

Terms related to working with AI models, APIs, and language models.

## Core Concepts

The fundamental ideas you need to work with AI:

- **[Model](./model.md)** — The AI system that generates responses
- **[Prompt](./prompt.md)** — Instructions you give to the AI
- **[API](./api.md)** — How your code talks to AI services

## Technical Details

Understanding how AI systems work:

- **[Token](./token.md)** — Basic unit of text that AI processes
- **[Context Window](./context-window.md)** — Maximum text a model can handle
- **[Context Engineering](./context-engineering.md)** — Deliberately shaping what information an LLM has access to
- **[RAG](./rag.md)** — Automatically retrieving relevant context from your documents

## Why These Matter

**For this workshop:**
- You'll write **prompts** to generate code
- You'll call **APIs** to analyze texts
- You'll engineer **context** so LLMs understand your project
- You'll stay within **context windows**
- You'll track **token** usage
- (Advanced) You might use **RAG** for larger projects

(See [development-tools](../development-tools/) for JSON and API keys)

**The key insight:**
Working with AI is like working with a very capable colleague — you need to know:
- How to communicate clearly (prompts)
- How to request services (APIs)
- What their limitations are (tokens, context windows)

## The Non-Technical Explanation

Think of it like this:

- **Model** = The AI assistant (like ChatGPT or Gemini)
- **Prompt** = What you ask the assistant to do
- **API** = A way to use the assistant from your code
- **Token** = How the assistant measures text
- **Context Window** = How much the assistant can "see" at once
- **Context Engineering** = Making sure the assistant knows about your project (it forgets everything between calls!)
- **RAG** = Automatically finding and including relevant information from your documents

## Learning Approach

You don't need to understand all technical details.

What you DO need:
- Know these concepts exist
- Understand roughly what they mean
- Recognize them when you see them
- Know where to look for details

What you DON'T need:
- Memorize pricing structures
- Understand tokenization algorithms
- Know all API specifications
- Master technical implementation details

AI and tools handle most technical details for you.
